## 🧭 일하는 방식 | Engineering Principles

| 원칙 | 실제 적용 |
|---|---|
| **현장 문제부터 정의** | 운영 질문을 측정 가능한 상태·행동·위험·평가지표로 변환 |
| **근거가 주장보다 먼저** | 데이터 명세, 해시, 평가계약, 기준선과 한계를 함께 공개 |
| **재현 가능한 실험** | 테스트, 결과 번들, 실행 문서와 변경 이력으로 결과 추적 |
| **사람이 최종 책임** | AI 에이전트별 기여를 기록하고 사람이 검수·승인·통합 |
| **끝까지 전달** | 코드에서 멈추지 않고 보고서·발표·데모·배포까지 연결 |
